highlight-pipeline

プライバシーポリシー

制定：2026年10月12日

highlight-pipeline（以下「本ツール」）は、YouTube チャンネルの所有者（以下「利用者」）からハイライト動画の制作を任された運用者が、動画の制作・アップロード・管理のために使うツールです。このページでは、本ツールが扱う情報と、その扱い方を説明します。

利用者は、本ツールに Google アカウントの許可を出す前に、このポリシーをお読みください。許可を出すことで、このポリシーに同意したものとします。

1. YouTube API サービスの利用

本ツールは YouTube API サービスを使っています。Google による情報の扱いについては、Google プライバシーポリシーをご覧ください。

2. 扱う情報

利用者の許可を得て扱う情報

  • 許可したチャンネルの名前（正しいチャンネルが許可されたかを確かめるために表示します）
  • 本ツールがアップした動画の ID と公開設定
  • 再生回数・視聴時間などのアナリティクスの数字（今後使う予定）
  • 許可の結果として Google が発行する認証情報（トークン）

公開されている情報

  • チャンネルの動画と配信の ID、タイトル、公開日時、配信の開始・終了の時刻、長さ
  • 配信の自動字幕

利用者側から受け取る情報

  • ハイライト動画の素材にする配信の動画ファイル

3. 使い道

扱う情報は、次の目的にだけ使います。広告への利用や販売はしません。

  • ハイライト動画の制作（素材にする配信を決める、字幕からテロップや見出しの案を作る）
  • ハイライト動画の限定公開でのアップロードと、公開状況の管理
  • 作業の記録と、運用者への作業の知らせ
  • 再生回数などをもとにした制作の振り返り（今後使う予定）

4. 保存する場所

  • 認証情報（トークン）：運用者のパソコンの中だけに保存し、運用者のアカウント以外からは読めない設定にしています。Google 以外には送らず、他人に渡しません。
  • 動画の ID・タイトル・URL・公開設定・作業の状況：運用者の管理表（Google スプレッドシート）と運用者のパソコンに記録します。
  • 素材の動画と、制作した動画：運用者の Google ドライブとパソコンに保存します。

5. 外部のサービスとの共有

作業のために、次のサービスに必要な範囲の情報を送ります。これ以外の第三者には、法令にもとづく場合を除いて、情報を提供しません。

  • Google（Google スプレッドシート・Google ドライブ）：管理表と動画の保存
  • Discord：運用者への作業の知らせ（動画のタイトルと URL を含みます）
  • Anthropic（Claude）：字幕の整理と、テロップ・見出しの案づくり（配信の字幕など、作業に必要な情報を送ります）

本ツールが第三者に広告などのコンテンツを配信させることはありません。

6. 利用者の端末について

本ツールは、利用者のパソコンやスマートフォンに情報を保存したり、そこから情報を集めたりしません。クッキーなども使いません。許可の手続きは Google の画面で行われます。

7. 保存期間と削除

  • 保存した情報は、ハイライト動画の制作・管理に必要な間だけ保存します。依頼が終わったときは、認証情報をすぐに削除し、ほかの情報も利用者との取り決めに沿って削除します。
  • 利用者は、いつでも保存した情報の削除を求めることができます。お問い合わせ先にご連絡いただければ、7日以内に削除します。
  • 本ツールが保存した情報を削除しても、YouTube 上の動画やデータは消えません。YouTube 上の動画を消すときは、YouTube Studio で操作してください。

8. 許可の取り消し

利用者は、Google アカウントのセキュリティ設定のページから、いつでも本ツール（highlight-pipeline）への許可を取り消せます。取り消すと、本ツールは利用者のチャンネルに接続できなくなります。保存した情報の削除は、7. の方法でお求めください。

9. お問い合わせ

本ツールでの情報の扱いについてのご質問やご意見は、運用者までご連絡ください。

GitHub の Issues からご連絡ください。Issues の内容は誰でも見られるため、メールアドレス・動画の URL・認証情報（トークン）などは書かないでください。

10. このポリシーの変更

このポリシーを変更するときは、このページを更新し、利用者にお知らせします。
