YouTube 向けハイライト動画の制作支援ツール

highlight-pipeline

highlight-pipeline は、YouTube 向けのハイライト動画づくりを手伝うツールです。YouTube チャンネルの所有者からハイライト動画の制作を任された運用者が、所有者の許可を得て使います。一般の方には提供しておらず、このページから申し込みやログインはできません。

できること

  • チャンネルの配信が終わったことを確かめる（公開されている情報を読むだけです）
  • 運用者が作ったハイライト動画を、所有者のチャンネルに「限定公開」でアップする
  • アップした動画が「公開」に切り替わったかを確かめる
  • 再生回数や視聴時間などの数字を読み、制作の振り返りに使う（今後使う予定）

このツールは、動画を「公開」にしません。内容を確かめたうえで、人が YouTube Studio で公開に切り替えます。動画の削除、コメントの投稿、チャンネルの設定の変更もしません。

Google アカウントの許可を求める理由

所有者には、Google の画面で次の3つの許可をお願いしています。

YouTube への動画のアップロードyoutube.upload
ハイライト動画を限定公開でアップするために使います。
YouTube アカウントの情報の表示youtube.readonly
許可したチャンネルが正しいかの確認と、アップした動画の公開設定の確認に使います。
YouTube アナリティクスのレポートの表示yt-analytics.readonly
再生回数や視聴時間などを読むために使います（今後使う予定）。

扱う情報とその扱い方は、プライバシーポリシーに書いています。許可を出す前にお読みください。

利用条件

このツールは YouTube API サービスを使っています。このツールを使うことで、利用者は YouTube 利用規約 に従うことに同意したものとします。

あわせて、このツールのプライバシーポリシーと Google プライバシーポリシー をご確認ください。

お問い合わせ

GitHub の Issues からご連絡ください。Issues の内容は誰でも見られるため、メールアドレス・動画の URL・認証情報（トークン）などは書かないでください。
